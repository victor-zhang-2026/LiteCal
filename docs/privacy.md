# 数据与隐私 / Data and privacy

LiteCal 无账号、服务器、联网业务、遥测、分析和广告。日程由应用独立管理，不读取系统日历，不连接 iCloud 或第三方日历，不申请通知、联系人或辅助功能权限。

事件与备份为未加密的本地 JSON，保存在当前用户的 `~/Library/Application Support/LiteCal/`。本机用户、系统备份工具和具有文件访问权限的软件仍可能读取文件；“本地”不代表额外加密或访问隔离。请自行保留所需备份。

LiteCal has no accounts, server, telemetry, advertising, or network-dependent features. It does not access Apple Calendar or external calendar accounts. Events and backups are unencrypted JSON in the current user's Application Support directory. Local storage is not an additional encryption or access-control layer, and there is no automatic cloud backup.
