# LiteCal 1.2.5

- 在月视图与周视图的原农历文字位置显示常见中国节日及二十四节气。节日与节气同一天时优先显示节日。
- 节气日期采用香港天文台 UTC+8 的逐年对照表，覆盖 1901–2100 年；农历闰月不重复普通节日，除夕按农历年末动态识别。
- 完全离线，不显示放假或调休标识，不向日程数据写入节日。

Chinese festivals and all 24 solar terms now appear in the existing lunar-date label in both month and week views. Solar-term dates cover 1901–2100 in UTC+8. Event data is unchanged.
